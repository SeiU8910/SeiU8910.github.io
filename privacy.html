Privacy notice

Updated: 2026-10-05. Application: Hermes Local Context (Personal).

Data accessed and purpose

The integration reads Google account email and display name to verify account selection, Drive file names and metadata to locate sources, and selected document or spreadsheet contents to support requested research, summaries and personal assistant tasks. Permissions are drive.readonly, documents.readonly and spreadsheets.readonly.

Storage

OAuth credentials, selected source snapshots, source metadata, assistant context, logs and local backups are stored on the owner's Mac. Token files use owner-only permissions. Local Git snapshots and backups can retain older versions until the owner deletes them. The configured assistant and memory services also run locally.

Processing and sharing

Selected contents and conversation context may be sent to the configured OpenAI language-model service when the assistant processes a request. Requested replies and files may be sent to the owner's Slack workspace. Other research services are not part of this Google integration. Information is not sold, used for advertising, or shared publicly by this integration.

This public information site

This site is hosted on GitHub Pages. GitHub may log visitor IP addresses for security purposes. This site does not request Google authorization or collect source documents, and does not add analytics or advertising scripts.

Controls and retention

The owner can revoke this application's access in Google Account linked-app settings, remove local credentials, and delete source snapshots, context, logs and relevant backups. Revocation stops future Google access but does not delete existing local copies or material previously sent to Slack or the model provider. Data retained by those services follows the relevant account settings and service policies. Local records remain until removed by the owner.

Limited use

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google data is used only for the requested assistant functionality described above, not to train or improve a general-purpose model through this integration.
